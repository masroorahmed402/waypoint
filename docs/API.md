# API Design — REST /api/v1

All endpoints JSON. Auth = `Authorization: Bearer <accessToken>` unless marked **public**. Live OpenAPI docs at `/api/docs` (generated by Nest Swagger — that is the always-current reference; this doc is the contract summary).

## Envelopes

Success: raw resource or `{ "data": [...], "nextCursor": "..." }` for lists.
Error (global filter, always this shape):
```json
{ "statusCode": 422, "error": "ValidationError", "message": ["dueDate must be a valid ISO date"], "requestId": "req_..." }
```

Validation: class-validator DTOs, `whitelist + forbidNonWhitelisted` (unknown fields → 400).
Pagination: cursor-based, `?cursor=&limit=` (max 100).
Rate limits (Redis-backed): global 100 req/min/user; auth endpoints 10 req/min/IP; presign 20 req/min/user.

## Auth (`/auth`) — public unless noted

| Method | Path | Body → Response |
|---|---|---|
| POST | /auth/register | `{email, password, firstName, lastName}` → `201 {user, accessToken}` + refresh cookie. Password: min 10 chars, zxcvbn score ≥ 3. |
| POST | /auth/login | `{email, password}` → `{user, accessToken}` + refresh cookie. Uniform error on bad email vs bad password (no user enumeration). |
| POST | /auth/refresh | (cookie) → `{accessToken}` + rotated refresh cookie. Reuse of an already-rotated token → revoke family, 401. |
| POST | /auth/logout | (authed) revokes refresh family, clears cookie → 204 |
| GET | /auth/google | → 302 to Google |
| GET | /auth/google/callback | → session pair, redirect to app |

## Users (`/users`)

| GET | /users/me | full profile incl. StudentProfile |
| PATCH | /users/me | update name, etc. |
| PUT | /users/me/profile | onboarding upsert: `{universityId?, universityName?, degreeLevel, major, programStartDate, programEndDate, visaType, usEntryDate?}` → triggers deadline recomputation |
| DELETE | /users/me | soft delete + schedule purge → 204 |

## Immigration (`/immigration`)

| GET | /immigration/timeline | computed milestones: `[{key, label, date|dateRange, status: PAST\|CURRENT\|UPCOMING, explanation, sourceUrl?}]` — every item includes plain-English explanation + official source link + "confirm with your DSO" flag |
| GET | /immigration/deadlines?status=upcoming | Deadline list, soonest first |
| POST | /immigration/deadlines | custom deadline `{title, dueDate, notes?}` |
| PATCH | /immigration/deadlines/:id | edit custom / dismiss any (`{dismissedAt}`) |
| DELETE | /immigration/deadlines/:id | custom only → 204 |

System deadlines are recomputed (upsert by dedupeKey) whenever profile or a document expiry changes.

## Documents (`/documents`)

| GET | /documents | metadata list (never URLs) |
| POST | /documents | `{type, fileName, contentType, sizeBytes, issueDate?, expiryDate?}` → validates (allowlist: pdf/jpg/png/webp; ≤ 20 MB; quota) → `201 {document, uploadUrl}` (presigned PUT, 60s) |
| POST | /documents/:id/confirm | verifies object exists + size/type match → `{document}` ACTIVE; expiryDate present → deadline upsert |
| GET | /documents/:id/download | → `{url}` presigned GET (120s) |
| PATCH | /documents/:id | metadata edits |
| DELETE | /documents/:id | soft delete; purge job removes S3 object after 30 days |

## Career (`/career`)

| GET | /career/applications?stage=&cursor= | list |
| POST | /career/applications | `{companyName, companyId?, roleTitle, url?, stage=SAVED, sponsorshipConfirmed?, notes?}` |
| PATCH | /career/applications/:id | any field; stage change writes ApplicationEvent |
| GET | /career/applications/:id/events | stage history |
| DELETE | /career/applications/:id | hard delete → 204 |
| GET | /career/companies?query= | typeahead (global table) |

## Health — public

`GET /health` liveness · `GET /health/ready` DB + Redis check.

## Permissions model

- STUDENT: full CRUD on own rows only (services always filter by JWT `sub`; ownership checked before mutation, 404 not 403 on foreign IDs — don't leak existence).
- ADMIN (Phase 2): university/company reference-data management. `@Roles('ADMIN')` + RolesGuard already scaffolded.
